- Engine stays GUI-free (spec §4.2). App adds `engine = { path = "../engine" }` and `viewer = { path = "../viewer" }`.
- libcosmic pinned at git rev `dbc62f2d899cdbfbe43d170689ddc0290db663f4` with feature `wgpu`; `cosmic-config` at the SAME rev (workspace dependency). NEVER a pop-os/iced.git dependency. wgpu 28 exact.
- Settings have ONE writer: engine `settings_path()` load/save (`~/.config/cad-studio/settings.json`). cosmic-config holds app-UI state only (recents path list, first-run flag). `Settings.recent_projects` and `Settings.has_completed_setup` are dead to the app in M4 (inert until M8 consolidates).
- User-visible strings via `fl!()` with keys from app/i18n/en/main.ftl (336 keys from M0). Missing key → add to en/main.ftl with upstream's English value, U+2019 apostrophes. No hardcoded English in views.
- All new app logic modules are pure (no cosmic/iced types) and unit-tested; widget files map only. Fake-agent fixtures drive every agent-path test — no network, no real CLI. App async tests copy engine's ENV_LOCK + bounded-poll pattern (session_lifecycle.rs:95-135), never fixed sleeps, never `env::set_var` (unsafe in edition 2024).
- thelio gates are controller-owned, single-invocation, never stacked, HEAD-verified after pull; GPU suites `-- --test-threads=1` until the harness fix lands (M3 T4b).
- Conventional commits; stage explicit paths only; never `git add -A`/`-u`; never `git rm`.
- Parallel-dispatch cap: implementers + controller ≤ 5 agents; reviewers stagger, never concurrent with a 4-implementer wave.

## Review Focus

Pinned by named tests (owner in parens; these are the failure modes no ordinary task test exercises):

1. **Drain-stall freezes cancel** — 256-deep channel backpressure + cancel polled only between translations (T3 `flood_does_not_wedge_cancel`).
2. **Auth 401 false-positive** — "1401 tokens"/"duration 4.401s" must not classify auth (T0 `auth_401_word_boundary_engine` + T1 auth/non-auth row tests).
3. **chat.json absent or corrupt on open** — opens with empty transcript, rewrites valid on save (T1 `corrupt_chat_json_opens_empty` via `load_chat(root).unwrap_or_default()` at the call site).
4. **Turn ends without TurnFinished** — channel closes first: tools fail open, queue leaves running state cleanly (T3 `channel_close_without_turn_finished`).
5. **Pane mutation loses layout** — split/drag/resize sequences round-trip through LayoutNode without sub-minimum panes (T4 `resize_clamps_min_thickness`).
6. **Streaming snapshots mis-modeled as deltas** — engine sends ACCUMULATED text per event (T1 snapshot-pair tests: "He","Hello" → "Hello").
7. **Schematic re-raster storm** — zoom gestures must debounce to cached buckets, never re-raster per wheel tick (T6 `zoom_debounces_to_buckets`).

### Task 1: Chat transcript reducer (pure)

**Files:** Create `app/src/chat.rs` (+ in-crate tests), `app/tests/chat_replay.rs`; Modify `app/src/main.rs` → `app/src/lib.rs` split, `app/Cargo.toml` (engine dep, tokio+serde dev-deps).

**Interfaces:**
- Consumes: Task 0's extended `EngineEvent`/`TurnOutcome`; `engine::project::store::{ChatMessage, ToolActivity, Action, save_chat, load_chat}`; `engine::agent::tool_summary::{live_title, live_preview}`.
- `ChatState { messages: Vec<ChatMessage>, active_thinking_id: Option<Uuid>, streaming_id: Option<Uuid>, thinking_started_at: Option<Instant>, unconfirmed: Vec<Uuid>, turn_had_confirmed_text: bool }`; `ChatState::new(persisted: Vec<ChatMessage>)` (callers do `load_chat(root).unwrap_or_default()` — upstream `(try? …) ?? []`).
- `apply_at(&mut self, event: &EngineEvent, now: Instant)` — the translation (upstream AgentSession.swift + ChatViewModel.swift); the `now` seam lets tests drive a fake clock:
  - `Started` → no row; resets `turn_had_confirmed_text` and drops any dangling open streaming row (upstream resets `hasText` per run, AgentSession.swift:35).
  - `ThinkingStarted` → append `role: thinking` row ("thinking" placeholder text per the en catalog), set `active_thinking_id` + `thinking_started_at = now`.
  - `Thinking { estimated_tokens }` → set that row's text to the "~N tokens" catalog format.
  - `ThinkingFinished` → set "reasoned for N s", `N = max(1, (now − thinking_started_at).as_secs_f64().round())`; id + start cleared.
  - `TextStreaming { text }` → **SET** the open streaming row's text to `text` (the payload is an accumulated SNAPSHOT, never a delta). The open streaming row is a member of `unconfirmed` AT CREATION (AgentSession.swift:232); new-block detection — the open row's text is not a prefix of `text` — merely opens a new row (also a member at creation).
  - `TextConfirmed { text }` → pop the FIRST unconfirmed row and `setText` on it; `unconfirmed` empty → append a confirmed row (fires only for text that never streamed); set `turn_had_confirmed_text`.
  - `ToolStarted { id, name, title }` → append row with `tool: Some(ToolActivity { name, tool_use_id: id, state: running, input: String::new(), preview: None, output: None })`, `text = title`.
  - `ToolInput { id, partial }` → append to `tool.input`; under the 0.15 s throttle (`should_emit_preview(last_emit, now)`), recompute `text = live_title(name, &input)` and `preview = live_preview(&input)`.
  - `ToolFinished { id, output, is_error }` → `complete_tool`: first recompute `text = live_title(name, &input)` and `preview = live_preview(&input)` over the ACCUMULATED input (upstream finalizes the title at the tool's block stop, AgentSession.swift:171-173; the engine emits no tool content-block-stop, so this is the only home — without it, a tool whose whole input streamed inside one 0.15 s window keeps a title computed from the first fragment), then set output + state = failed/succeeded; **preview is kept** (upstream completeTool sets output+state only; only failRunningTools clears preview).
  - `System { text }` → append system row.
  - `TurnFinished(Success { text, .. })` → fail-open tools; clear thinking; if `!turn_had_confirmed_text && !text.is_empty()` append `text` as an assistant row (engine already applied the hasText rule — app appends only when no confirmed row arrived).
  - `TurnFinished(Failed { error, auth, exit_code })` → fail-open tools; clear thinking; append a system row: auth → login-command text + `action: Some(Action::OpenTerminal)` + `detail = error`; non-auth → the "ended with an error (code N)" catalog line with `exit_code`, `detail = error`. `auth` here is the ENGINE flag post-Task-0 (word-boundary needle); the reducer does NOT re-classify.
  - `TurnFinished(Cancelled | Busy | MissingSession)` → fail-open tools; clear thinking; Cancelled appends the summary "Interrupted" row.
- `fail_running_tools()` (running→failed, preview cleared), `can_send()`, `take_draft()` — ChatViewModel.swift verbatim.

**Tests:** `snapshot_streaming_sets_not_appends` ("He","Hello" → "Hello"; single-block + confirm: TS("He"), TS("Hello"), TC("Hello") → exactly ONE row, text "Hello"; two-block snapshots → two unconfirmed rows, first confirmed in place); `thinking_row_lifecycle` (start→tokens→finish text forms, duration ≥1 s rule via the `apply_at` fake clock); `tool_lifecycle_full` incl. name + preview kept on completion + final title reflects the FULL input when the tail landed inside one throttle window; `fail_open_at_turn_end`; `auth_row_persists_open_terminal_action` (save_chat → load_chat round-trip keeps the action); `non_auth_failure_row_carries_exit_code`; `corrupt_chat_json_opens_empty`; `success_no_text_appends_turn_text` (incl. a two-turn replay: a later no-text turn still appends its fallback after an earlier text turn); replay integration `app/tests/chat_replay.rs` (fake-agent scenarios → final transcript asserted).

**Steps:** lib/bin split → tests → RED → implement → GREEN (`cargo test -p app`) → commit `feat(app): chat transcript reducer — engine events to persisted rows`.
